🎯 HOW IT WORKS:
═══════════════════════════════════════════════════════════════════════

WITHOUT MODEL (Demo Mode):

WITH MODEL (ML Mode):
  Camera → MediaPipe Hands → Capture Frame → Flask API → 
  CNN Model → Prediction → Display Result

📊 MODEL ARCHITECTURE:
═══════════════════════════════════════════════════════════════════════

Input: 28×28×1 (grayscale hand image)

Conv2D(32) → BN → ReLU
Conv2D(32) → BN → ReLU → MaxPool → Dropout(0.25)

Conv2D(64) → BN → ReLU
Conv2D(64) → BN → ReLU → MaxPool → Dropout(0.25)

Conv2D(128) → BN → ReLU
Conv2D(128) → BN → ReLU → MaxPool → Dropout(0.25)

Flatten → Dense(512) → BN → ReLU → Dropout(0.5)
         → Dense(256) → BN → ReLU → Dropout(0.5)
         → Dense(27) → Softmax

Output: 27 classes (A-Z + space)
